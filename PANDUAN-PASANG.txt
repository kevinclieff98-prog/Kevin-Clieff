# Website Kevin Clieff Emor — Pelatihan & Sertifikat

## File dalam paket
- `index.html`: website yang sudah diperbarui.
- `sertifikat/`: berisi salinan PDF dan gambar pratinjau dokumen yang diberikan pengguna.
  - `surat-keterangan-lulus-pembinaan-ak3u-ijs.pdf` (halaman 3)
  - `data-management-staff-bnsp.pdf` (halaman 1–2)
  - `sertifikat-penunjang-k3-lengkap.pdf` (17 sertifikat halaman 4–20)
  - Setiap sertifikat penunjang juga tersedia sebagai PDF tersendiri.
  - `seluruh-dokumen-asli-20-halaman.pdf` (salinan PDF asli).
- `dokumentasi/`: folder foto seminar, PKL, dan foto angkatan (foto belum diberikan).

## Cara memasang di GitHub Pages
1. Ekstrak ZIP.
2. Buka repositori GitHub Pages `kevinclieff98-prog.github.io` milik Anda.
3. Pastikan salinan file lama disimpan sebagai cadangan sebelum diganti.
4. Unggah `index.html` dan folder `sertifikat/` ke root repositori. **Pertahankan struktur folder dan nama file.**
5. Tunggu GitHub Pages selesai mempublikasikan perubahan.
6. Buka https://kevinclieff98-prog.github.io/ dan uji bagian "Sertifikat".
7. Untuk foto kegiatan, unggah foto asli ke folder `dokumentasi/` dengan nama: `seminar-1.jpg`, `seminar-2.jpg`, `pkl-1.jpg`, `pkl-2.jpg`, `angkatan-1.jpg`, `angkatan-2.jpg`.
